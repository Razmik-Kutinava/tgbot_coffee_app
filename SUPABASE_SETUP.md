# Инструкция по настройке Supabase

## Шаги для подключения бота к Supabase

### 1. Установка зависимостей

Установите необходимые библиотеки:
```bash
pip install -r requirements.txt
```

### 2. Создание таблиц в Supabase

1. Откройте ваш проект в Supabase Dashboard: https://supabase.com/dashboard
2. Перейдите в раздел **SQL Editor**
3. Откройте файл `supabase_schema.sql` и скопируйте его содержимое
4. Вставьте SQL код в редактор и нажмите **Run**

Это создаст следующие таблицы:
- `users` - для хранения данных пользователей (геолокация, баллы, реферальный код)
- `orders` - для хранения истории заказов пользователей

### 3. Проверка подключения

Бот автоматически подключится к Supabase при запуске. Проверьте логи:
```
Подключение к Supabase установлено
```

Если видите ошибку, проверьте:
- Правильность URL и ключа в `bot.py`
- Что таблицы созданы в Supabase
- Что RLS (Row Level Security) отключен или настроен правильно для service_role ключа

### 5. Как это работает

1. **При первом запуске /start**:
   - Пользователь создаётся в таблице `users`
   - Сохраняются имя, username, telegram_id

2. **При отправке геолокации**:
   - Геолокация сохраняется в `users.location_latitude` и `users.location_longitude`
   - При повторном заказе геолокация передаётся в WebApp автоматически

3. **При заказе из WebApp**:
   - Заказ сохраняется в таблицу `orders`
   - Связывается с пользователем через `user_id`

4. **При просмотре истории заказов**:
   - Заказы загружаются из таблицы `orders` для конкретного пользователя
   - Отображаются в порядке от новых к старым

### 6. Важные замечания

⚠️ **Безопасность**:
- Service Role Key имеет полный доступ к базе данных
- Не публикуйте этот ключ в публичных репозиториях
- Используйте переменные окружения для продакшена

⚠️ **Row Level Security (RLS)**:
- Для service_role ключа RLS обычно не применяется
- Если используете anon ключ, настройте политики доступа

### 7. Проверка работы

После настройки проверьте:
1. Запустите бота: `python bot.py`
2. Отправьте команду `/start` - пользователь должен создаться в БД
3. Отправьте геолокацию - она должна сохраниться
4. Откройте историю заказов - должны отображаться заказы из БД

### 8. Просмотр данных в Supabase

Для просмотра данных:
1. Откройте Supabase Dashboard
2. Перейдите в **Table Editor**
3. Выберите таблицу `users` или `orders`
4. Просмотрите сохранённые данные
