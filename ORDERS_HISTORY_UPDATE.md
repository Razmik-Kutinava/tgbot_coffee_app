## Как это работает:

1. **При нажатии на "История заказов"**:
   - Бот получает последние 3 заказа из Supabase
   - Отображает первый заказ с кнопкой "Повторить заказ"
   - Можно переключаться между заказами кнопками `<<` и `>>`

2. **При нажатии на "☕ Повторить заказ"**:
   - Открывается WebApp с URL параметрами:
     - `action=repeat_order`
     - `order_id=<ID заказа>`
     - `order_name=<Название заказа>`
     - `modifiers=<Список модификаторов>`
     - `latitude=<Широта>` (если сохранена)
     - `longitude=<Долгота>` (если сохранена)

3. **WebApp получает данные**:
   - Может использовать `order_id` для загрузки полных данных заказа
   - Может использовать `modifiers` для предзаполнения модификаторов
   - Может использовать `latitude` и `longitude` для предзаполнения геолокации
